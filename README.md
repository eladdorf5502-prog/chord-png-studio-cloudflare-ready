# Chord PNG Studio

A desktop-first personal guitar chord diagram editor. Choose a preset, edit any string or visual setting, and export a deterministic transparent PNG at 1024, 2048, or 4096 pixels.

## Run locally

1. Install dependencies with `pnpm install`.
2. Start the editor with `pnpm dev`.
3. Open the local URL shown in the terminal.

The current chord, visual design, and export resolution are stored only in the browser with `localStorage`.
